## Diseño de interfaz

Para cualquier tarea que implique crear, modificar o revisar vistas, componentes, navegación, formularios, tablas, estados vacíos, indicadores, mensajes o experiencia de usuario:

1. Lee y aplica la skill `.codex/skills/ui-ux-pro-max/SKILL.md`.
2. Conserva Vue 3, Bootstrap 5 y SCSS como stack visual obligatorio.
3. No introduzcas Tailwind, Vuetify, PrimeVue, Quasar ni otro framework visual.
4. Antes de implementar una pantalla nueva, define:
   - objetivo del usuario;
   - acción principal;
   - riesgos de error;
   - jerarquía visual;
   - estados loading, empty, error, success y disabled;
   - comportamiento con grandes volúmenes de información.
5. La interfaz debe sentirse institucional, contable, sobria, clara y productiva.
6. Evita dashboards genéricos, tarjetas decorativas y elementos sin función.
7. Todo cambio visual debe conservar accesibilidad, contraste, navegación por teclado y estados focus visibles.
